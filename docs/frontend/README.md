# frontend

ブラウザで使う Webアプリ。学生と教員が使う12画面。

技術: **TypeScript**、**React + Vite + Tailwind CSS**（ENG-013。提出版は React + TypeScript）。PC・スマートフォンの両方に対応する。UIは日本語のみ。

## 設計書上の担当範囲

画面は12。サインインしたアカウントが学生か教員かで、ホーム画面が分かれる。教員の操作はすべて教員ホームから1〜2段で届く。

| A_A0001_SD0001 | サインイン | 全員 | A_A0001 |
| A_S0002_SL0001 | 学生ホーム（受講授業一覧） | 学生 | A_S0002 |
| A_S0002_SL0002 | 授業別出欠記録 | 学生 | A_S0002 |
| A_S0003_SL0001 | 教員ホーム（担当授業一覧） | 教員 | A_S0003 |

## 守る約束

- 受付中の「授業回別出欠一覧」は自動更新する（R-03-4）。
- 「学生別欠課時数一覧」は、欠課時数の多い学生を強調し、書き出しボタンを持つ（R-03-5）。書き出しは希望機能。
- 文言は [メッセージ台帳](../engineering/catalog/messages.md) のIDで参照し、直接書かない。
- 学生証のカードIDは画面に出さない。
- XSS対策: React の自動エスケープを使い、HTMLの直接埋め込みをしない。
- セッションは最終操作から30分で失効する（Cognito のトークンとの関係は未決。N-08）。
- サインインは Cognito の **Hosted UI** を使う。ユーザープールは学生用と教員用の2つなので、サインイン画面（A_A0001_SD0001）の入口を分ける（ENG-004。分け方は未決。N-05）。提出版の「Microsoft 365 のサインインへ誘導する入口」から変更している。
- Cognito との接続は最終フェーズ（ENG-005）。それまでは仮のサインインで画面を動かす（N-07）。
- 権限のない画面を開いたら `SYSCOMMON_E000101` を表示する。
