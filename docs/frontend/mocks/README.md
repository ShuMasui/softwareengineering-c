# mocks

Webアプリの画面モックを置く。

## ルール（案）

- モックのファイル名は**画面IDで始める**（例: `A_S0002_SL0001.png`、`A_S0002_SL0001.html`）。どの画面のモックかを、ファイル名だけで分かるようにする。
- 画面に出す文言は、[メッセージ台帳](../../engineering/catalog/messages.md) と [コード台帳](../../engineering/catalog/codes.md) に合わせる。
- モックの形式（画像・HTML・Figma など）は未定。決まったら `../decisions.md` に記録する。
