# mocks

Webアプリの画面モック。**操作できます**（画面の遷移、入力、エラーの分岐）。

## 見方

リポジトリのルートで、次を実行してブラウザで開く。

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory docs
```

- Webアプリ: http://localhost:8000/frontend/mocks/
- 受付アプリ（[windows/mocks](../../windows/mocks/index.html)）: http://localhost:8000/windows/mocks/

## 画面の構成

- **右**: PCのブラウザ画面の中に、1画面ずつ表示する。リンクやボタンを押すと、画面が移る（URL欄も変わる。左上の ← で戻れる）。
- **左**: ユースケース（CUJ）。ステップを押すと、その画面を表示する。**▼ 分岐**を開くと、選択肢（正常・エラーなど）が出る。
- **画面の下**: 選んだ分岐で何を試すかの説明が出る。
- **右上**: 「モックを初期状態に戻す」。

## ユースケース（CUJ）

| CUJ | 分岐 |
|---|---|
| 学生が自分の欠課時数を確認する | 登録済みのアカウント／初めてのサインイン（招待メールの仮パスワード）。見る授業を選ぶ |
| 教員が受付中の出欠を見て、修正する | 受付中／未実施の授業回。修正は、成功／理由なし（`A_S0004_E000001`）／競合（`A_S0004_E000002`） |
| 教員が欠課の多い学生を確認する | 授業の選択。書き出しは、記録あり／記録なし（`A_F0002_W000001`） |
| 教員が授業を登録し、受講学生を取り込む | 名簿は、誤りなし／誤りあり（`A_F0001_E000001`、保存できない） |
| 教員が学生と学生証を登録する | 新規登録（招待メール）／学生証の無効化 |
| 異常系: 権限のない画面を開く | 学生で教員の画面を開く（`SYSCOMMON_E000101`） |

## ルール（案）

- 画面に出す文言は、[メッセージ台帳](../../engineering/catalog/messages.md) と [コード台帳](../../engineering/catalog/codes.md) に合わせる。
- データはモックの中だけにあり、再読み込みで初期状態に戻る。サーバにはつながない。
- 画面IDを、`index.html` の画面の定義（`SCREENS`）のキーにしている。
