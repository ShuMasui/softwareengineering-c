# mocks

Webアプリの画面モック。

- **[index.html](index.html)**: 12画面を1ファイルにまとめた簡易モック。ブラウザで開く。上のリンクから画面を行き来できる（動作はしない）。
- 各画面は、画面IDを `id` にした `<section>` になっている（例: `index.html#A_S0002_SL0001`）。

## ルール（案）

- 画面に出す文言は、[メッセージ台帳](../../engineering/catalog/messages.md) と [コード台帳](../../engineering/catalog/codes.md) に合わせる。
- 見た目の品質は問わない。画面の項目と流れが分かれば足りる。
- モックを増やすときも、画面IDを `id` かファイル名の先頭にする。
