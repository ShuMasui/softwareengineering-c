# メッセージ台帳

出典: [基本設計書](../basic-design.md) 8.2。ID の構成は `機能ID ＋ _ ＋ レベル（E/W/I）＋ 連番6桁`。

- レベル: **I**＝情報、**W**＝警告、**E**＝エラー
- 文言の `{0}` `{1}` は、実行時に値を差し込む場所

| メッセージID | レベル | メッセージ | 表示する場面 | 備考 |
|---|---|---|---|---|
| A_S0001_I000001 | I | {0}さん　{1} | 申告成功 | {0}＝氏名、{1}＝出席・遅刻・欠課 |
| A_S0001_I000002 | I | {0}さんは申告済みです | 2回目のタッチ | {0}＝氏名 |
| A_S0001_W000001 | W | 読み取れませんでした。もう一度かざしてください | 読み取り失敗 | |
| A_S0001_E000001 | E | 登録されていない学生証です。担当の先生に申し出てください | 未登録の学生証 | |
| A_S0001_E000002 | E | この授業の受講学生ではありません | 受講対象外 | |
| A_S0001_E000003 | E | 受付が終了しています | 締切後のタッチ | |
| A_S0004_E000001 | E | 修正理由を入力してください | 理由未入力 | |
| A_S0004_E000002 | E | 他の人が先に更新しました。画面を開き直してください | 楽観的排他の競合 | |
| A_S0005_E000001 | E | この学生証は別の学生に登録済みです | 学生証の重複登録（R-05-2） | |
| A_F0001_E000001 | E | 名簿の{0}行目：{1} | 名簿取込エラー（学籍番号なしなど） | {0}＝行番号、{1}＝内容 |
| A_F0002_W000001 | W | 書き出す出欠記録がありません | 記録なしで書き出し | |
| SYSCOMMON_E000101 | E | この画面を表示する権限がありません | 権限外のアクセス | 共通（機能IDの代わりに SYSCOMMON） |

## 受付画面の表示（A_S0001_SD0001）

設計書6.4。判定結果の見た目は、メッセージとは別に決まっている。

| 結果 | 色 |
|---|---|
| 出席 | 緑 |
| 遅刻 | 黄 |
| 欠課・エラー | 赤 |
| 申告済み | 青 |

- 結果は、かざした直後の3秒間表示する。
- 音は成功音とエラー音の2種類。どの結果にどちらを鳴らすかは設計書に指定がない（windows 側で決める）。
