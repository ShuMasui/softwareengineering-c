# catalog

画面に出す文言と、コード値の**台帳**。backend・frontend・windows が同じ文言・同じ値を使うために、ここを1か所の正とする。

| ファイル | 内容 | 設計書 |
|---|---|---|
| [messages.md](messages.md) | メッセージ一覧（ID・レベル・文言・表示する場面） | 8.2 |
| [codes.md](codes.md) | コード一覧（出欠区分・入力区分・受付状態など） | 8.1 |

## 運用

- 文言・コード値を変えるときは、**コードより先にこの台帳を直す**。コード側は台帳のIDで文言を参照し、文言をコードに直接書かない。
- メッセージIDとコード値は、一度使ったら再利用しない。使わなくなったものは行を消さず、備考に「廃止」と書く。
- 文言は日本語のみ（多言語対応しない）。
- 提出版と違う文言・値にするときは、ユーザーの確認を得て、該当領域の `decisions.md` に「提出版との差」を記録する。
- 画面の項目ラベル（ED06）は提出版で省略している。画面の実装で必要になったら `labels.md` を足す。
