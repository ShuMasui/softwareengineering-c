# windows

教室のWindows PCで動く**受付アプリ**。学生証を読み取って結果を表示するだけで、出欠の判定はしない（判定はサーバ）。

技術（設計書3章）: C#（.NET、WPF）。PC/SC で学生証のIDを取得し、結果を画面と音で表示する。リーダーは PaSoRi RC-S300。通信はHTTPSのみで、Webアプリと同じAPIを呼ぶ。

## 設計書上の担当範囲

| 画面ID | 画面名 | 利用者 | 機能ID |
|---|---|---|---|
| A_S0001_SD0001 | 授業選択・受付 | 教員・学生 | A_S0001 |
| A_S0005_SD0002 | 学生証登録モード | 教員 | A_S0005 |

- 授業選択・受付: 今の時間の授業を選んで受付を開始し、かざした結果を表示する。項目は設計書6.4。
- 学生証登録モード: 学生を順に選び、学生証をかざして続けて登録する（R-05-1, R-05-4）。

## 守る約束

- 教員が受付アプリにサインイン（Cognito の教員ユーザープール、Hosted UI。ENG-004。方式は未決でN-06。提出版は Microsoft Entra ID）すると、担当授業のうち今の時刻に合う授業回が自動で選ばれる。教員の操作は「受付開始／終了」の1ボタンだけ。
- 受付を開始できるのは授業開始の30分前から（設定値）。
- 読み取りに失敗したら、サーバへ送らず「もう一度かざしてください」を表示する（`A_S0001_W000001`）。
- サーバへは、授業回ID・カードID・受付トークンを送る。
- 結果の色: 出席＝緑、遅刻＝黄、欠課・エラー＝赤、申告済み＝青。かざした直後3秒表示する。音は成功音とエラー音の2種類。
- 申告人数／受講者数（例「32 / 40」）と、判定の切替までの残り時間（「遅刻まであと○分」）を受付中に表示する。
- 学生証のカードIDは画面に出さない。
- セッションは、受付中の授業が終わるまで維持する。
